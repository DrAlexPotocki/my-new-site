1. Общая информация о проекте

Разрабатывается новый сайт для врача мануального терапевта Олександра Потоцького.

Сайт создаётся с нуля на HTML, CSS и JavaScript с использованием Vite.

Старый сайт am.if.ua продолжает работать. До завершения разработки, тестирования и утверждения нового сайта никаких изменений на старом сайте не производить.

Основные требования и концепция будущего сайта описаны в PROJECT_SPEC.md.

2. Технологии и рабочая среда

Операционная система: Arch Linux.

Редактор кода: Visual Studio Code.

Технологии: HTML, CSS, JavaScript.

Сборщик: Vite.

Локальный адрес разработки: http://localhost:5173/.

Папка проекта: /home/arch_user/Projects/my-new-site.

Основные файлы:

index.html — главная страница.

booking.html — отдельная страница записи и контактов.

src/main.js — логика главной страницы.

src/style.css — общие стили.

src/components/ — общие компоненты.

src/scripts/ — отдельные JavaScript-модули.

src/data/ — общие данные сайта.

src/pages/ — логика отдельных страниц.

4. Что важно учитывать

Главная страница в целом готова, поэтому дальнейшая работа не должна ограничиваться только ею.

Следующий этап — разработка остальных разделов и внутренних страниц сайта.

Главная страница может дорабатываться параллельно, если обнаружатся недочёты.

Необходимо по возможности использовать общие компоненты и централизованные данные, чтобы избежать дублирования.

Не менять выбранный технологический стек без отдельного согласования.

Старый сайт не трогать до утверждения нового.

5. Рабочие договорённости

Пользователь только начинает работать с веб-разработкой, поэтому:

Объяснять действия простым и понятным языком.

Давать инструкции последовательно, небольшими шагами.

Всегда указывать точный путь к файлу.

При изменении кода объяснять, что именно найти, заменить или добавить.

Не предлагать большие объёмы кода без необходимости.

Перед изменением существующего кода учитывать его текущую структуру.

Не считать задачу выполненной, пока пользователь не подтвердит результат.

После завершения важных этапов актуализировать этот файл.
